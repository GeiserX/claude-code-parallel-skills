# Moved to agent-skills

These skills now live in [GeiserX/agent-skills](https://github.com/GeiserX/agent-skills), and this repository is archived.

The versions there no longer need oh-my-claudecode. Each one scales its agent panel to the task instead of starting at seven. The same skills also come as Codex copies. The commands dropped the `!`: `/review-pr!` is now `/review-pr` in Claude Code and `$review-pr` in Codex.

- [Parallel skills](https://github.com/GeiserX/agent-skills/blob/main/docs/skills.md#parallel-skills): `investigate`, `review-pr`, `review-code`, `research`, `implement`
- [Installation](https://github.com/GeiserX/agent-skills/blob/main/docs/installation.md) for Claude Code and Codex
- The loops that used to be copied here (`goal-loop`, `refine-loop`, `docs-loop`) are maintained there too, with `goal-loop` as `sergio-loop`.
